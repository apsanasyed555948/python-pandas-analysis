# Pandas CSV Data Analysis

## Objective

The objective of this project is to demonstrate data analysis skills using Pandas.

## Requirements Covered

- Load and inspect a CSV dataset
- Clean missing data
- Remove incorrect data
- Apply filtering
- Apply grouping and aggregation
- Explain insights in simple words

## Dataset

The project uses a sample sales dataset containing:

- Product
- Category
- Quantity
- Price

## Data Cleaning

The program:

1. Replaces missing quantity values with 0.
2. Removes rows containing zero or negative prices.
3. Calculates total sales.

## Analysis

The program filters sales greater than 1500 and groups the data by product.

It calculates:

- Total quantity
- Total sales
- Average sales

## Insight Summary

The analysis identifies the product with the highest total sales and total quantity sold. The data was cleaned by handling the missing quantity and removing the incorrect negative price.

- Python
- Pandas
- CSV
